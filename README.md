# GEI Open Research Initiative

**A DAM TEAM OF GENIUS. Six disciplines. One open investigation.**

A professional, mobile-first research portal inviting qualified and independent contributors to examine GEI (Genesis Engineered Interpretation) — an alternative interpretive framework examining Genesis 1–6 through proposed linguistic, textual, hydraulic, water-management, archaeological, and mechanical-engineering comparisons.

## Live Features

### Public (no authentication required)
- **Landing page** — Mission, six discipline pathways, process overview, FAQ
- **Evidence Room** — Four transparent research entries with full methodology documentation
- **Discipline invitations** — Detailed pathway descriptions for each research area
- **Application form** — Low-friction researcher interest form with discipline pre-selection
- **Privacy notice** — Complete data practices documentation

### Authenticated (requires account)
- **Dashboard** — Contributor workspace with role-based navigation
- **Submissions** — Create and manage research contributions (questions, critiques, analyses, references, corrections)
- **Profile** — Account and attribution preferences
- **Review queue** — Reviewer-only submission review interface
- **Admin panel** — User management, application review, audit log

## Six Disciplines

1. **Hebrew Scholars** — THE LANGUAGE INVESTIGATION
2. **Biblical Researchers** — THE TEXTUAL INVESTIGATION
3. **Civil Engineers** — THE STRUCTURAL INVESTIGATION
4. **Hydrologists** — THE WATER INVESTIGATION
5. **Archaeologists** — THE ANCIENT TECHNOLOGY INVESTIGATION
6. **Mechanical Engineers** — THE MECHANICAL INVESTIGATION

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Authentication:** Auth.js (NextAuth v5)
- **Validation:** Zod
- **Database:** In-memory (dev) / PostgreSQL (production)

## Research Integrity

GEI is not presented as academic consensus, an established Hebrew translation, proven ancient hydraulic technology, or confirmed archaeological discovery. This initiative distinguishes observation, analogy, hypothesis, evidence, and unresolved questions. Critical review and corrections are invited.
